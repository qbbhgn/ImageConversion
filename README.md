# 图片转换工具箱 (Image Conversion)

一个基于 **Vue 3 + TypeScript + Vite** 的纯前端图片转换工具。

可以将图片 / GIF 转换为 **Base64、SVG、HTML、CSS** 等代码，并支持**分辨率调整**（等比放大 / 缩小，非裁剪）。所有处理均在浏览器本地完成，图片不会上传到服务器。
